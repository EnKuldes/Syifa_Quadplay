# Syifa Quadplay

This is an app I have developed for my previos Job on November 2019. The purpose of this app is to distrubute to each agents and be consumed to call/verify our company clients. This proccess includes few step such as uploading data by Team Leader, distributing based on agent click/consume button, sumbitting agent form, verifying the form by QA, and lastly generating report.

This app use Laravel as the main framework and MySQL/MariaDB as the RDBMS.
